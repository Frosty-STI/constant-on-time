# Synthetic fixtures

This directory is reserved for generic, reproducible learning fixtures. The
initial build generates waveforms, noise, mismatch, load steps, and fault cases
from documented equations and deterministic seeds in `@constant-on-time/sim-core`
and the application lab models; it does not contain laboratory, customer, or
employer data.

Scenario files exported by the application can be stored here for future
regression studies after reviewing them for generic values and secrets. Keep
the seed, model abstraction, units, and applicable operating range with every
fixture.
